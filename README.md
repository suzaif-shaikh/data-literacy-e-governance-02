# 📊 E-Governance Data Visualization and Analysis

## 📌 Project Overview
This project focuses on analyzing e-governance services using data visualization techniques in Microsoft Excel. It explores application trends, service performance, resolution rates, and citizen satisfaction across different states and digital services.

## 🎯 Objectives
- Analyze e-governance application data.
- Calculate key performance indicators (KPIs).
- Identify monthly application trends.
- Compare service performance across states.
- Present insights through an Excel dashboard.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization
- KPI Analysis

## 📂 Dataset Description
The project uses a simulated dataset containing **300 records** across:
- 5 States
- 5 Digital Services
- 12 Months

Key attributes include:
- Total Applications
- Resolved Applications
- Pending Applications
- Average Processing Time
- Citizen Satisfaction
- Resolution Rate
- Complaint Rate

## 📈 Visualizations
The Excel dashboard includes:

1. **Bar Chart:** Compares application volumes across digital services.
2. **Line Chart:** Shows monthly application trends.
3. **Heat Map:** Highlights citizen satisfaction across states and services.
4. **KPI Dashboard:** Displays key performance indicators.

## 🔍 Key Insights
- Analyzed a total of 328,435 applications.
- Achieved an overall resolution rate of 87.2%.
- Compared service performance across five states.
- Identified trends in application volumes and citizen satisfaction.

## 💡 Conclusion
This project demonstrates how Excel-based data analysis and visualization can transform raw data into meaningful insights. These insights can help identify performance gaps and support better decision-making in digital public services.
